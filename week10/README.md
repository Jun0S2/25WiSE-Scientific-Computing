### Automated Check Script for Exercise 10

run 'bash check.sh' to check your exercise.
The output of your program should be of the format:

cargo run --release apfelmeanchen.pgm 2

Algorithm 1 Checksum: <hex>, computed <integer> pixel in <float> ms = <float> Mpx/s
Algorithm 2 Checksum: <hex>, computed <integer> pixel in <float> ms = <float> Mpx/s
...

For each algorithm you implemented, where algorithm 1 is thread-based and algorithm 2 is MPI-based. Feel free to add more versions.
Please upload a pfd with your performance table containing the algorithm, CPU, OS, Compiler, Cores/Th., Scale, S-Thread, threads, MPI, and different Flags in the zip folder.
